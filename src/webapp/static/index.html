Paste a student submission and the system will score it, explain the score in named writing habits, mark the sentences it reacted to, and draw verification questions from the student's own claims.

Your text never leaves this computer. This looks like a website, so that claim is worth checking rather than taking on trust. The page is served from 127.0.0.1, which is this machine talking to itself, and every model is loaded inside that same process. You can pull out the network cable and the analysis below still runs. That matters because a student submission is personal data, and the argument for building this pipeline on a laptop rather than an API rests on exactly this property.
